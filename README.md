## 🌟 Highlights

- **Iconic PotPlayer Frameless Dark Skin**: Borderless dark chrome, custom window controls, and floating auto-hiding playback controls inspired by PotPlayer.
- **⚡ Multi-Tab Architecture**: Open Video, Audio, and Image files in separate independent tabs within one single window.
- **⇲ File Takeover Mode (`Tab` / `F10`)**: Instant transition from Multi-Tab mode into pure borderless single-media immersion where the active file takes over 100% of the canvas. Move your mouse to the top to peek and switch tabs anytime.
- **Universal Media Engine**:
  - 🎬 **Video**: Hardware-accelerated GPU playback (Direct3D 11 / OpenGL), MP4, MKV, WebM, MOV, AVI, etc.
  - 🎵 **Audio**: High-fidelity audio player with real-time frequency visualizer canvas (MP3, FLAC, WAV, AAC, OGG, Opus).
  - 🖼️ **Image**: Pan and zoom viewer with mouse-wheel scaling, rotation (`R`), and instant 1:1 view.
- **Instant Drag & Drop**: Drop any combination of media files directly into the window to open as tabs.
- **Zero Bloat**: Lightweight, fast startup (<50ms), no 360-dll clutter like legacy codec packs.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Tab` / `F10` | **Toggle File Takeover Mode** (collapse / expand tab bar) |
| `Space` | Play / Pause |
| `F` / `F11` | Fullscreen Toggle |
| `Ctrl + O` | Open Media File(s) |
| `Ctrl + T` | New Media Tab |
| `Ctrl + W` | Close Current Tab |
| `Ctrl + Tab` | Switch to Next Tab |
| `Ctrl + Shift + Tab` | Switch to Previous Tab |
| `→` / `←` | Seek Forward / Backward (5s) |
| `↑` / `↓` | Volume Up / Down (5%) |
| `M` | Mute / Unmute |
| `R` | Rotate Image 90° clockwise |
| `0` | Reset Image Zoom & Pan to 1:1 |

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/ZaxMil/VeloxTab.git
cd VeloxTab

# Install dependencies
npm install

# Start the player
npm start
```
